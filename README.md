# Typing Test

A Python-based typing test that measures typing speed and accuracy.

## Features

- Different difficulty levels
- Random typing passages
- Calculates time taken
- Calculates words per minute (WPM)
- Calculates typing accuracy
- Shows correct and incorrect characters
- Shows extra and missing characters
- Displays total errors

## Technologies Used

- Python
- JSON

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `main.py`.
4. Select a difficulty level.
5. Start typing and view your results.

## Project

This project was created as a Python practice project to learn about
user input, file handling, JSON data, string comparison, and calculations.
